# AI 프롬프트북 1013

이미지·영상 생성 프롬프트 1013개(1~10권)를 모은 교안용 웹 프롬프트북입니다.

- 카드를 누르면 예시 이미지와 프롬프트 전문을 크게 볼 수 있어요.
- **복사하기**: 프롬프트를 클립보드에 복사
- **프롬프트 공유**: 휴대폰 공유창(카카오톡 등)이 열리고 프롬프트 글만 전송 (링크 없음). 카카오톡 안에서 열었을 때는 외부 브라우저로 열기 안내가 나옴
- **이미지 + 프롬프트 공유**: 예시 이미지 파일과 글을 함께 전송 (링크는 보내지 않음, 프롬프트는 자동 복사)
- 검색, 권별·종류별 필터, 즐겨찾기(★), 글자 크게(가+)

## 폴더 구성
```
index.html   화면
prompts.js   프롬프트 데이터 (제목·분류·본문)
img/         예시 이미지 1013장 (1-001.jpg ~ 10-100.jpg)
img/ref/     7권·10권 첨부(참고·제품) 이미지 — 이미지 만들 때 함께 올리는 사진
video/       영상 예시 9개
.nojekyll    GitHub Pages 설정 파일
```

## GitHub Pages 올리기
1. GitHub에서 새 저장소(예: `promptbook`)를 만듭니다. (Public)
2. 이 폴더 안의 파일과 폴더를 **그대로** 저장소 맨 위에 올립니다.
   - 웹 업로드는 한 번에 100개까지라 img 폴더는 여러 번 나눠 올리거나, GitHub Desktop을 쓰면 한 번에 올라갑니다.
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://아이디.github.io/promptbook/` 으로 접속합니다.

## 프롬프트 수정
`prompts.js`에서 해당 번호(예: `"id":"1-004"`)를 찾아 `"t"`(제목) 또는 `"x"`(본문)를 고치면 됩니다.
분류 코드: P 인물·화보 · C 캐릭터·일러스트 · A 제품·광고 · D 포스터·디자인 · N 동물·풍경 · V 영상
